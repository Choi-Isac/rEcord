# 고려대학교 탄소발자국 계산기 웹사이트 제작

## 핵심 기능
- 이용자의 데이터를 바탕으로 탄소 배출량 계산

## 구현 단계

### 1단계

#### 탄소발자국 계산기

1. 입력 방식
    - 간편 입력(1분 내외): 칩 선택/슬라이더 형식으로 빠르게 입력
    - 자세히 입력(5분 내외): 간편 입력의 세부 사항을 정확한 값으로 입력
    - 정밀 입력(15분 이상): 자세히 입력의 항목에 추가하여 탄소발자국과 관련된 항목 입력 가능
2. 제시 방식
    - 계산기 시작 화면에서 간편 입력/정밀 입력 선택지 제공
    - 간편 입력 페이지에서 자신이 원하는 항목만 접기/펼치기 형식으로 '자세히 입력' 가능하게 하기
    - 정밀 입력의 항목 입력 순서는 간편 입력과 비슷한 순서로 따라가지만 추가 입력 항목은 적절한 위치에 추가됨
    - 간편 입력과 정밀 입력은 입력 도중에 전환 가능
    - 간편 입력의 내용을 바탕으로 자세히 입력 항목의 기본값을 결정
    - 간편 입력과 정밀 입력을 전환할 때는 자세히 입력의 입력값을 정밀 입력에 동일하게 옮김, 반대도 마찬가지.

#### MVP 테스트 구현 순서

MVP의 목적은 모든 기능을 구현하는 것이 아니라 아래 가설을 검증하는 것이다.

**검증 가설**
1. 간편 입력이 1분 내외로 완료되고, 이용자가 결과를 이해하고 신뢰하는가
2. '자세히 입력'을 펼치는 이용자 비율은 얼마이며, 간편 입력 대비 결과는 얼마나 달라지는가
3. 결과 확인 후 감축 행동 의향과 재방문 의향이 생기는가
4. 익명 집계 데이터가 대학·지자체에 제공할 수 있는 수준으로 쌓이는가

**구현 순서**

| 순서 | 할 일 | 산출물 | 완료 기준 |
|---|---|---|---|
| 1 | 가설과 측정 지표 확정 | 지표 목록(완료율, 소요 시간, '자세히' 펼침 비율, 간편 대비 자세히 결과 차이, 이해도·신뢰도 설문, 재방문 의향) | 성공/실패 기준에 팀 합의 |
| 2 | 계산 엔진 설계 (화면보다 먼저) | 스프레드시트 프로토타입: 배출계수표, 칩 대표값 매핑, 수단별 평균 속도(편도 시간 → 거리), 거주 형태별 기본값, 연간 환산 | 가상 이용자 사례 3~4개를 손계산과 대조해 일치 |
| 3 | 데이터 모델과 동의 구조 설계 | 응답 스키마, 동의 문구(서비스 이용 / 통계·연구 활용 분리), 집계 시 최소 응답 수 기준 | 원본 입력값을 저장하는 구조 확정 |
| 4 | 종이/피그마 프로토타입 + 사용성 인터뷰 | 학생 5~8명 테스트 결과, 문항 수정안 | 소요 시간 측정, 이해되지 않은 문항 파악 |
| 5 | 간편 입력 + 결과 화면 구현 (v0.1) | 시작 화면, 간편 입력 13개 항목, 영역별 기여도, 범위 표시, '추정' 배지, 가장 큰 항목 1개 + 감축 제안 3개 | 입력부터 결과까지 완주 가능 |
| 6 | 자세히 입력 펼침 구현 (v0.2) | 항목·섹션 단위 접기/펼치기, 값 덮어쓰기 규칙, '직접 입력' 배지 | 간편 대비 자세히 결과 비교 가능 |
| 7 | 계측과 집계 화면 구현 | 단계별 이탈·소요 시간 로그, 관리자용 익명 집계 화면 | 최소 응답 수 미만 집계는 숨김 |
| 8 | 파일럿 (1개 대학, 수업·동아리 단위 30~100명) | 수정 후 재시행하는 2회 반복 | 지표 결과 정리 |
| 9 | 다음 단계 결정 | 정밀 입력 / 재측정·챌린지 / 대학 대시보드 중 우선순위 | 데이터 근거로 선택 |

**MVP 범위**
- 포함: 간편 입력(14개 항목), 자세히 입력 펼침, 결과 화면, 익명 집계
- 제외: 정밀 입력(시작 화면의 정밀 입력 선택지는 숨김 또는 '준비 중' 표시), 간편↔정밀 전환, 데이터 연동·업로드, 디지털·대학 활동 모듈, 챌린지·순위, 포인트 제도 연동(안내 링크만 제공), 대학 대시보드, API

**확장을 위해 미리 반영할 것**
- 결과값이 아니라 원본 입력값을 저장하여 배출계수 변경 시 재계산 가능하게 하기
- 응답마다 배출계수 버전과 입력 방식(간편/자세히) 플래그 기록
- 응답 학기 정보 기록(재측정·변화 추적용)
- 대학·학과는 선택 항목으로 받고, 거주 지역은 결과 화면에서 받아 탄소중립포인트·에코마일리지 안내에 활용

**결정이 필요한 사항**
- 배출계수 출처와 기준 연도 (2단계의 선행 조건)
- 파일럿 대상 대학과 모집 방법 (환경 관심 학생 편중을 줄이기 위해 수업 단위 모집 권장)
- 개발 방식(노코드 / 직접 개발)과 팀 규모에 따른 단계별 일정
